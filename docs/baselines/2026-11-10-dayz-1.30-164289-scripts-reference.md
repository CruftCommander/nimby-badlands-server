## What changed between 164200 and 164289

`diff -rq` of the two extracts (`logs/extract-164289/diff-164289.txt`): 27 files differ, none added, none removed. All 27 are script files; no `config.cpp`, layout, or data file changed. Going by path and file name, most are base building, code locks, the diag menu, the heat modifiers, and the warhead bunker.

Two changes are more than moved lines:

- `PlayerConstants.c:206` and `:208`: `THERMAL_BIAS_POSITIVE_HC_DECREMENT` goes from `0.0001` to `0.0002`, and `THERMAL_BIAS_POSITIVE_HC_LOW_INCREMENT` from `0.00022` to `0.0002`.
- `BaseBuildingBase.c:65`: a `SetAllowDamage(true);` line is removed.

`Game.c` gains one comment line at 1346 and a `CollisionFlags flags` parameter on `IsBoxCollidingGeometry` at 1365. The other files were not read line by line for this record.
