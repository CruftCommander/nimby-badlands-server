   `pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-NimbyTestServer.ps1 -BuildPath .\build\@NIMBY-20261019-152515 -ServerPath D:\DayZServer -InstanceId 999 -ProfileName legs-phase1`
5. Start the client with the same build:
   `pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-NimbyTestClient.ps1 -BuildPath .\build\@NIMBY-20261019-152515 -Connect 127.0.0.1 -Password <join password the server printed>`
6. Evidence lives in two places: server lines in `profiles\legs-phase1\script_*.log` (and the `logs\testserver-<stamp>` copy), client lines in `%LOCALAPPDATA%\DayZ\script_<date>.log`. Every `Toggle` line carries `side=client` or `side=server`; a matched pair is one client line and one server line with the same `running` and `idx`.

Line forms (plan, Logging): `Toggle player=<name> (<bi-id>, <steam64>) running=<bool> idx=<n> side=<side> cause=<cause>`; `Forced clear player=... reason=<reason> via=<hook|tick>`; `Cancel received player=... reason=<reason> wasRunning=<bool>`; `Start refused player=... cause=<cause>`; `Rejected request from <bi-id>, <steam64>: <reason>`; `Throttled player=... count=<n>`.
