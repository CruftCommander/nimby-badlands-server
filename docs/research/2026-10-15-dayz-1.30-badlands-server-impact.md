# DayZ 1.30 and Badlands: server impact for NIMBY Badlands

Research pass of October 15, 2026, about 8:30 AM CT, on release day. It combines Bohemia's published notes, hosting-company write-ups, mod pages, and what the live server (HostHavoc service 246248) shows after its first Nasdara boot.

Bohemia's 1.30 stable notes were not indexed on release morning. Every claim below therefore carries a confidence label:

| Label | Meaning |
| --- | --- |
| **Observed** | Seen on our server: files, RPT, script log, or console log. |
| **Bohemia** | Stated in a Bohemia changelog or announcement (experimental 1.30.164014 unless noted). |
| **Secondary** | Stated by a hosting company or wiki, not traced to a Bohemia source. |
| **Unverified** | Open question; the check that resolves it is listed. |

## What this is not

- Not the 1.30 stable changelog. Re-check every **Secondary** and **Unverified** row once Bohemia's stable notes are readable.
- Not a loot (`types.xml`) tuning plan. It records stock values as a starting point only.
- Not a decision record. Decisions stay in the Notion hub; this page feeds them.

| Priority | Item | Action |

### Stock `cfggameplay.json` on Nasdara

The file is `"version": 130` (Chernarus and Sakhal in Bohemia's repository are 123).

| Key | Nasdara stock | Note | Confidence |
| --- | --- | --- | --- |
| `WorldsData.lightingConfig` | `3` | Bohemia's repository has Chernarus `0` and Sakhal `2`, so the value is a per-map lighting profile, not a bright/dark switch. Keeping `3` was correct; forcing `1` would apply a non-Nasdara profile. | Observed |
| `PlayerData.disablePersonalLight` | `true` | Stock on Nasdara | Observed |
| `SandstormData.sandstormFrequency` | `1.0` | Undocumented. Likely a multiplier on storm frequency. | Observed; meaning Unverified |
| `VehicleData.canDetachAttachedCarWheels`, `canDamageAttachedCarWheels`, `canDetachAttachedBikeWheels`, `canDamageAttachedBikeWheels` | all `true` | The 1.30 "disable detaching and damaging of wheels" setting | Observed + Bohemia |
| `ExternalLockData.protectionCountStageOne` / `StageTwo` / `protectionTime` / `protectionResetTime` | `3` / `1` / `30` / `3600` | Likely the new code-lock brute-force lockout | Observed; meaning Unverified |
| `WorldsData.bunkerBroadcastEnabled` | `true` | Likely the Morse radio signals to underground shelters | Observed; meaning Unverified |
| `BaseBuildingData.HologramData.disableColdAreaPlacementCheck` | `true` | Sakhal-era cold-area check, off on Nasdara | Observed |
| `PlayerData.WeaponObstructionData.staticMode` / `dynamicMode` | `1` / `1` | Undocumented on the Bohemia wiki | Observed |

Our overrides (applied October 15, 2026): stamina 5 kg at 2.0%/kg, hit direction off, and the two hologram checks relaxed. See `server/mission-overrides/README.md`.

## Gameplay changes with server consequences

| Change | Server consequence | Confidence |
| --- | --- | --- |
| Motorbikes (Jana 50, Bitrak 682) on all maps | New vehicle class in the economy; one seat, no inventory, blowtorch repair, spark plug damage at speed | Bohemia + Secondary |
| Vanilla code lock (`DigitalCodeLock`) on all maps | Needs a charged 9V battery and opens when it runs flat; brute-force lockout grows per failed PIN | Secondary |
| Rebuildable houses on Nasdara (about 5,000, about 20 variants) | More persistent player-built state; trowel, bricks, and mortar | Secondary |
| Sandstorms, heat, and water scarcity | Hydration pressure; dust goggles are in loot (`DustGoggles_*` nominal 55) | Secondary + Observed |
| Underground shelters via Morse signals | New terrain-hole system; `disallowedTypesInUnderground` blocks fence kits, flag kits, and watchtowers underground | Secondary + Observed |
| Barbed and metal wire no longer repairable with duct tape | Base raid balance | Bohemia |
| Exploit fix: weapons loading any ammo type | None to do | Bohemia |
| Vehicle-specific third-person server option | See Summary item 1 | Bohemia; name and default Unverified |
| `-limitFPS` now matches the limit on Windows | HostHavoc launch line has no `-limitFPS` | Bohemia + Observed |
