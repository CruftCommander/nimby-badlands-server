## 2. Decisions Jeff makes before step 1

1. **Release artifact contents.** `scripts/Build-NimbyPack.ps1` packs every addon in `pack.json`; nothing selects a subset, and 9.3 puts only release-qualified PBOs in the Workshop item. Options: a build parameter that names the addons to pack (shared-file change, one session), or a release-only pack definition. Recommendation: the parameter, so every later single-mod release uses the same path. **Ruled (Jeff, October 26, 2026): the build parameter.** `Build-NimbyPack.ps1` gains `-Addons` naming the addons to pack (release 1: `NimbyAutorun,NimbyEarplugs,NimbyNotes,NimbyGreet`); orchestrator-owned, so it lands in the next orchestrator session, before step 2 (brief: `logs\brief-release-build-params-20261026.md`).
2. **Boot instance.** `pack.json` `bootCheck.instanceId` is 999 (the fresh world). Step 9.2.1 boots against a copy of live `storage_1`, which `Sync-LiveReplica.ps1` places in `storage_998`. Options: a parameter for the instance, or editing `pack.json` for the gate run. **Ruled (Jeff, October 26, 2026): a build parameter**, `-BootInstanceId 998`, in the same orchestrator change as decision 1; `pack.json` is not edited for the gate.
3. **Vanilla control (9.2.2).** The vanilla boot exists: `Start-NimbyTestServer.ps1 -ServerPath D:\DayZServer -InstanceId 998 -Vanilla` boots the same server build with no `-mod=` and keeps the RPT. The missing piece is the comparison: nothing yet sets the release boot's RPT counts beside the vanilla boot's (or `docs/baselines/`) and fails on an increase. Options: a comparison script, or a by-hand count table in the gate record. **Ruled (Jeff, October 26, 2026): the by-hand count table** in this record at step 3 (`SCRIPT (E)`, `Scripted variables corrupted`, save-load lines, release boot beside vanilla boot); the comparison script is a post-release item.
4. **Hands permission (9.3).** The Hands permission capture is a release blocker for the Workshop item; with Hands held out of this release, confirm whether `PERMISSION.md` still blocks. **Ruled (Jeff, October 26, 2026): capture it before publishing even though Hands is not in the artifact.** Captured the same evening from the Workshop page (item 2903112334, posted December 17, 2022, updated April 1, 2023), verbatim: "Repack/Modify/Redistribute" / "You ARE ALLOWED to repack, reupload, modify and redistribute this mod however you want." / "Don't ask me for any special features requests or whatever. I will not do any special versions for anyone. Just take the mod and make adjustments as you need and publish the adjusted version!" Written into `mods/own/nimby-pack/NimbyHands/PERMISSION.md` and approved by Jeff the same evening; CR-007 closed.
5. **Workshop publishing.** No script publishes; `scripts/Copy-WorkshopItem.ps1` copies a subscribed item into `vendor\`. Publishing is manual (DayZ Tools Publisher) on Jeff's Steam account. **Stands (no other path): manual on Jeff's Steam account.**
